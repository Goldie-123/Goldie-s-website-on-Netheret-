How to Fix a Windows software Update Problem?

Windows software updates help protect your computer, fix problems and improve performance. Sometimes updates fail to download or install. This guide explains some steps you can try.

10 Steps to Troubleshoot Windows Update

Step 1: Run the Windows software Update Troubleshooter
  1. Select Start and open Settings.
  2. Select System, then Troubleshoot.
  3. Choose Other troubleshooters.
  4. Find Windows Update and select Run.
  5. Follow the instructions on the screen.
Step 2: Check your Internet connection
  1. Open Start and select Settings.
  2. Choose Network & Internet, then Wi-Fi.
  3. Check that your device is connected to the Internet.
  4. Reconnect to your Wi-Fi or Ethernet if necessary.

For more help, visit Microsoft's Wi-Fi troubleshooting guide .

Step 3: Check Administrator access

Some updates require administrator permission. If your account does not have administrator access, ask your IT support team or device administrator for help.

Learn more about creating a Windows administrator account .

Step 4: Disconnect external hardware

Disconnect unnecessary external devices, such as USB drives, external storage, docks and other accessories. Try Windows Update again.

Step 5: Clear the Windows Update Cache

Damaged temporary update files can sometimes cause installation errors.

  1. Press Windows + R on your keyboard.
  2. Type services.msc and press Enter.
  3. Find Windows Update in the services list.
  4. Right-click it and select Stop.
  5. Open File Explorer and navigate to C:\Windows\SoftwareDistribution.
  6. Delete the contents inside the folder, not the folder itself.
  7. Return to Services, right-click Windows Update and select Start.
Important safety advice: Ask an IT administrator for help if you are unsure. Do not delete files from other Windows system folders.
Step 6: Check Date and Time settings
  1. Open Start and select Settings.
  2. Choose Time & language.
  3. Select Date & time.
  4. Enable Set time automatically.
  5. Enable Set time zone automatically if available.
  6. Select Sync now if necessary.
Step 7: Update third-party drivers

Outdated or incompatible drivers can prevent updates from installing correctly.

  1. Identify the hardware causing the problem.
  2. Visit the manufacturer's official website.
  3. Check for compatible driver updates.
  4. Follow the manufacturer's installation instructions.
Step 8: Free up storage space

Windows needs enough free storage space to download and install updates.

Microsoft gives minimum storage requirements of 16 GB for upgrading a 32-bit operating system and 20 GB for a 64-bit operating system in the guidance used for this article. Actual requirements can vary.

Visit Microsoft's guide to freeing up drive space .

Step 9: Run Windows Update again
  1. Open Start and select Settings.
  2. Select Windows Update.
  3. Choose Check for updates.
  4. Download and install any available updates.
Step 10: Restart your computer

Some updates need a restart before they can finish installing.

  1. Save your work and close open applications.
  2. Select Start.
  3. Choose Power.
  4. Select Update and restart or Update and shut down.

Common Windows Update Error Codes

The following table explains some common error codes and their possible causes.

Error Code Possible Cause
0x8007000d Damaged Windows Update files or cache.
0x800705b4 Update took too long or was interrupted.
0x80240034 Incomplete update or connection problem.
0x800f0922 Insufficient storage or problems with system components.
0x80070057 Incorrect settings or corrupted files.
0x80080005 Possible permission or system configuration issue.
0xC1900101 Driver compatibility problem.
0x80248014 Windows Update database or service problem.
0x80070005 Access denied or insufficient permissions.
0x80070002 Update files may be missing.

When to Contact IT Support

If you have followed these steps and Windows Update still does not work, contact the IT support team. Include the error code and explain which troubleshooting steps you have already tried.
