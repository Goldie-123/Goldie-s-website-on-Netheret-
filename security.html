Security and Network Troubleshooting

Welcome to the Security and Network support guide. This page provides information to help users understand common computer security and network problems.

Follow the troubleshooting guidance to help protect your device and maintain a reliable network connection.

Network and Security Topics

1. How to protect your computer from viruses

Use trusted antivirus software to help detect and remove malicious programs.

  • Keep your antivirus software updated.
  • Run regular security scans.
  • Avoid downloading files from unknown websites.
  • Do not open suspicious email attachments.
2. How to create a strong password

Strong passwords help protect your accounts from unauthorized access.

  • Use long, unique passwords.
  • Avoid using personal information.
  • Do not reuse the same password everywhere.
  • Consider using a trusted password manager.
  • Enable two-factor authentication where available.
3. How to improve network security

Secure your Wi-Fi network to help prevent unknown people from accessing your connection.

  • Change the router's default administrator password.
  • Use WPA2 or WPA3 Wi-Fi security where supported.
  • Keep your router firmware updated.
  • Use a strong Wi-Fi password.
4. What to do if your Internet connection is slow
  • Restart your router and modem.
  • Check whether other devices have the same problem.
  • Move closer to your Wi-Fi router.
  • Disconnect devices that are not being used.
  • Contact your Internet provider if the problem continues.
Security warning: Never share your passwords with strangers. Do not install unknown software or click suspicious links. Contact IT support if you think your device has been compromised.

Need More Help?

If these suggestions do not solve your problem, contact the Netheret IT support team. Explain what happened and include any error messages.
